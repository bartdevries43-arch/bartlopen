# bartlopen Run Coach

Openbare website en gratis 10 km e-book voor bartlopen Run Coach.

## Pagina's

- `/` - hoofdlink die doorverwijst naar de coachingspagina
- `/start/` - social-link en e-bookdownload
- `/coaching.html` - aanbod, voorbeeld-app en gratis kennismakingsbericht

De site werkt zonder buildstap en wordt gepubliceerd via GitHub Pages.
